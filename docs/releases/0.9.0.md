# Vibe Player v0.9.0

Vibe Player is a personal Android video player built on libmpv, featuring MX Player-style touch gestures, high-fidelity styled ASS subtitles, hardware decoding via MediaCodec, and optimized software AV1 decoding via dav1d. Developed for the POCO X5 Pro 5G and published as is.

## What's new in 0.9.0
This release is about smooth 4K and safe subtitles.
- **Smooth 4K**: videos larger than 1440p now play without dropped frames. They use zero-copy hardware decoding on OpenGL ES; before, a 4K 60 fps video showed only 10-30 frames a second in Quality mode. With the renderer set to Vulkan the old path stays (for HDR output).
- **Subtitles in any script stay readable**: Unicode subtitle files (UTF-8, UTF-16 with or without a BOM, UTF-32) are always read as Unicode, so Kurdish, Arabic, Japanese and other scripts keep their letters; the Subtitle encoding setting is only used for old non-Unicode files.
- **Controls after pausing**: a pause tapped just as the controls faded out now brings them back.
- **Subtitle folders**: subtitles next to a video also load automatically when another app opens the video by its /sdcard path.
- Developer settings (process exit diagnostics, system profile collection) are no longer shown in release builds, and profiling is never switched on there.

## Requirements
- **OS & Architecture**: Android 17 (SDK 37) on `arm64-v8a`. The app is compiled exclusively for 64-bit ARM (`minSdk = targetSdk = compileSdk = 37`).
- Tested and tuned on the POCO X5 Pro 5G (Snapdragon 778G) running DerpFest 17.

## Install and Update
- **Signing Key**: Both debug and release builds are signed with the developer's local Android debug key (`~/.android/debug.keystore`).
- Updates install in place and keep watch history and settings when installed over a build signed with the same key. The database is upgraded on first start; an update from 0.7.0 keeps the history (checked on the device).
- If you previously installed a build signed with a different key, you must uninstall the existing app first (which erases app data).

## Known Issues
- **B-08 Start Stall (H.264 zero-copy)**: H.264 zero-copy decoding occasionally stalls on the first frame; the built-in watchdog recovers automatically by reloading in software on a fresh surface.
- **Anime4K, FSRCNNX and RAVU are Vulkan-only**: on OpenGL ES these presets show a notice instead of running.
- **No network on some ROMs**: if links and servers time out, the ROM may be blocking network for new apps (DerpFest: restricted networking mode). Turn on Settings > Apps > Vibe Player > Mobile data and Wi-Fi > Network access.
- **Vulkan Experimental with Fallback**: the Vulkan renderer needs Vulkan 1.2+ driver support. If Vulkan fails, playback falls back to OpenGL ES.
