# Vibe Player v0.8.0

Vibe Player is a personal Android video player built on libmpv, featuring MX Player-style touch gestures, high-fidelity styled ASS subtitles, hardware decoding via MediaCodec, and optimized software AV1 decoding via dav1d. Developed for the POCO X5 Pro 5G and published as is.

## What's new in 0.8.0
This release is about watching series.
- **Up next**: when an episode ends, a card counts down to the next file in the folder (5 s by default; Off, 10 or 15 s in Settings) with Play now and Cancel.
- **Resume chip**: a video that opens where you left it shows "Resumed at 12:30" with a Start over button for a few seconds.
- **Bookmarks**: More > Bookmarks saves spots in a video, named after the chapter, so you can jump back later.
- **Per-show settings**: More > Whole folder applies the current speed to every episode in the folder, and turns auto-skip of openings and endings on or off for that show only.
- **Previous / next subtitle line**: two buttons in the Subtitles panel to hear a line again or skip ahead.
- **Rename and delete**: long-press a video in the browser. Android asks for permission first; position, tracks and bookmarks follow a renamed file.
- **Hidden folders**: long-press a folder to hide it from the list, search and Continue Watching. Settings > Library > Hidden folders shows it again.
- **Shaders while watching**: More > Shaders switches between Off, Anime4K A/B/C and Snapdragon GSR without leaving the video, and Compare shows the original picture for a side-by-side feel.
- **Stats overlay**: now also shows the codec, pixel format, colour space, active shaders, A/V sync and buffered seconds.
- **Backup and restore**: Settings > Library saves your history, bookmarks and settings to one file and brings them back after a reinstall.

- **Network playback**: the 🌐 button in the library opens Network. Play a link (http, https, HLS, DASH, RTSP, UDP and more), or add your SFTP or SMB server, FTP, WebDAV (Nextcloud, NAS), a web folder, a DLNA media server found on your Wi-Fi, or an IPTV / M3U playlist with its groups. Next episode, Up next and subtitles next to the video work there too. Passwords are stored encrypted. Vibe Player now has internet access, used only when you open something from Network.

## Fixed
- Videos filmed upright on a phone now open in portrait, with a portrait mini player. They used to open sideways because the rotation flag in the file was ignored.

## Requirements
- **OS & Architecture**: Android 17 (SDK 37) on `arm64-v8a`. The app is compiled exclusively for 64-bit ARM (`minSdk = targetSdk = compileSdk = 37`).
- Tested and tuned on the POCO X5 Pro 5G (Snapdragon 778G) running DerpFest 17.

## Install and Update
- **Signing Key**: Both debug and release builds are signed with the developer's local Android debug key (`~/.android/debug.keystore`).
- Updates install in place and keep watch history and settings when installed over a build signed with the same key. The database is upgraded on first start (bookmarks and per-folder settings are added).
- If you previously installed a build signed with a different key, you must uninstall the existing app first (which erases app data).

## Known Issues
- **B-08 Start Stall (H.264 zero-copy)**: H.264 zero-copy decoding occasionally stalls on the first frame; the built-in watchdog recovers automatically by reloading in software on a fresh surface.
- **Anime4K is Vulkan-only**: on OpenGL ES the presets show a notice instead of running.
- **Vulkan Experimental with Fallback**: the Vulkan renderer needs Vulkan 1.2+ driver support. If Vulkan fails, playback falls back to OpenGL ES.
