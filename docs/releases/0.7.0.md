# Vibe Player v0.7.0

Vibe Player is a personal Android video player built on libmpv, featuring MX Player-style touch gestures, high-fidelity styled ASS subtitles, hardware decoding via MediaCodec, and optimized software AV1 decoding via dav1d. Developed for the POCO X5 Pro 5G and published as is.

## What's new in 0.7.0
- **Chapters**: ticks on the seek bar, the chapter name while scrubbing and in the top bar, and a chapter list to jump around.
- **Skip opening and ending**: a skip button appears on chapters named Opening, OP, Ending, ED or Credits. Auto-skip can be turned on in Settings.
- **Volume boost**: the volume swipe and volume keys go past the media maximum, up to 150 % or 200 %.
- **Night mode**: evens out loud music and quiet dialogue for late-night watching.
- **Equalizer**: 10 bands with presets (Flat, Bass boost, Voice, Treble, Loudness), from the Audio panel.
- **ViPER4Android and other equalizer apps** now see Vibe Player's audio as soon as a video plays.
- **Subtitle folders and encoding**: subtitles next to a video in a granted folder load automatically. Subtitles in UTF-16 or older code pages (Arabic, Cyrillic, CJK and others) are converted so they display correctly.
- **Subtitle text style**: colour, outline, background box and bold for SRT and other plain subtitles.
- **More panel**: sleep timer, A-B repeat, loop this video, rotate, and picture adjustments (brightness, contrast, saturation, gamma).
- **Frame step** forward and back while paused.
- **Search** across all videos or inside a folder, with the best matches first and the folder name shown in results.
- **Watched mark**: a ✓ on videos you have finished.
- **Compact panels**: audio, subtitles, speed, sync, chapters and More open as a side panel in landscape, so the video stays visible. The portrait top bar now fits.
- **DerpFest 17 colours**: the app follows the system Material You theme, so it matches the ROM.

## Changed
- **Anime4K is Vulkan-only**: the Adreno OpenGL ES compiler rejects the Anime4K passes, so on OpenGL ES the presets now load nothing and show "Anime4K needs the Vulkan renderer" instead of running a broken chain. Snapdragon GSR still works on both renderers.

## Requirements
- **OS & Architecture**: Android 17 (SDK 37) on `arm64-v8a`. The app is compiled exclusively for 64-bit ARM (`minSdk = targetSdk = compileSdk = 37`).
- Tested and tuned on the POCO X5 Pro 5G (Snapdragon 778G) running DerpFest 17.

## Install and Update
- **Signing Key**: Both debug and release builds are signed with the developer's local Android debug key (`~/.android/debug.keystore`).
- Updates install in place and keep watch history and settings when installed over a build signed with the same key.
- If you previously installed a build signed with a different key, you must uninstall the existing app first (which erases app data).

## Known Issues
- **B-08 Start Stall (H.264 zero-copy)**: H.264 zero-copy decoding occasionally stalls on the first frame; the built-in watchdog recovers automatically by reloading in software on a fresh surface.
- **Vulkan Experimental with Fallback**: the Vulkan renderer needs Vulkan 1.2+ driver support. If Vulkan fails, playback falls back to OpenGL ES.
- **HEVC 10-bit 4K Drops**: the operating-rate hint to MediaCodec helps on tested clips; more tuning is ongoing.
